# Todo App

A simple React todo app integrated with SmartHeal SDK for error monitoring and auto-fixing.

## Features

- Add, toggle, and delete todos
- SmartHeal integration for error detection and fixes

## Setup

1. Install dependencies: `npm install`
2. Run the app: `npm run dev`
3. Ensure SmartHeal backend is running on `http://localhost:3001`

## SmartHeal Integration

The app uses SmartHeal SDK to capture and report errors to the backend for analysis and potential auto-fixes via GitHub PRs.
